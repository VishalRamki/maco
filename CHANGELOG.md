# v1.2.0

## Added

- Added support for adding categories and tags when saving new URLs.
- Added a dedicated settings dialog popup for upcoming configuration options.
- Added a factory reset option to clear all local data and start fresh.
- Added initial support for client/server connection selection.

## Fixed / Changed

- Fixed an issue where dashboard tiles could no longer be resized.
- Fixed a UI layout bug on the tile deletion control.
- Updated the window design by replacing the native window title bar with an integrated in-app toolbar, consolidated into the app icon.
- Refactored core codebase and added inline documentation to improve server integration support.

## Not Fixed / In Progress

- Category and tag management still has minor edge-case issues under active development.
- Server API integration remains in flux while server-side endpoints are being developed.
